# 📊 Task 1 – Data Cleaning & Preparation

> **DecodeLabs Data Analytics Internship | Project 1**

This repository contains **Project 1 – Data Cleaning & Preparation** completed as part of the **DecodeLabs Data Analytics Internship**.

The objective of this project was to transform a raw dataset into a clean, structured, and analysis-ready dataset by identifying missing values, removing duplicate records, correcting inconsistent data formats, and ensuring data integrity using **Microsoft Excel**.

Data cleaning is one of the most critical steps in the data analytics workflow because reliable insights begin with high-quality data.
